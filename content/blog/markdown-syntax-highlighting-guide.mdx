Writing blog posts in MDX gives you the full power of markdown combined with React components. In this post, we'll explore how syntax highlighting, table of contents, and rich markdown rendering come together to create a great reading experience.

## Getting Started with MDX

MDX is a format that lets you seamlessly write JSX in your markdown documents. You can import components, such as interactive charts or alerts, and embed them within your content.

Here's a simple example of a React component:

```tsx title="components/hello.tsx"
export function Hello({ name }: { name: string }) {
  return <h1>Hello, {name}!</h1>
}
```

The component above renders a greeting. You can use it directly in your MDX files.

## Using the Table of Contents

A table of contents improves navigation for longer articles. It automatically generates links from the headings in your post, allowing readers to jump to specific sections.

The table of contents on this page is generated from the `## ` and `### ` headings in this MDX file.

### How It Works

The TOC is built using `mdast-util-toc` and `remark`. Here's a simplified version:

```typescript
import { toc } from "mdast-util-toc"
import { remark } from "remark"

export async function getTableOfContents(content: string) {
  const result = await remark()
    .use(() => (node, file) => {
      const table = toc(node)
      file.data = extractItems(table.map)
    })
    .process(content)

  return result.data
}
```

### Active Heading Tracking

The TOC component uses an `IntersectionObserver` to track which section the reader is currently viewing, highlighting the corresponding item in the sidebar.
